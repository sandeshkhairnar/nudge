# Nudge 🚀

Nudge is a modern **workspace collaboration platform** designed to help teams manage projects, tasks, channels, and communication in one place. It enables teams to collaborate efficiently with real-time messaging, task management, and workspace organization.

---



## Features

- 🏢 **Workspaces** – Create and manage multiple workspaces
- 📁 **Projects** – Organize work into structured projects
- 👥 **Workspace Members** – Invite and manage team members
- 💬 **Channels & Messaging** – Real-time team communication
- 📌 **Tasks Management** – Assign and track tasks
- 🔔 **Notifications** – Stay updated with activity alerts
- 📨 **Invitations System** – Invite users via email
- 📂 **Resources** – Share important files and links
- ⚡ **Real-time Collaboration**
